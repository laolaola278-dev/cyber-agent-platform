# CAP v1 API Guide

## Source of truth

The source of truth is the OpenAPI document generated by the running backend at `/openapi.json`. This guide is an orientation layer and must not be treated as a substitute for the generated schemas. Before an integration release, export the OpenAPI document from the exact image under review and compare it with the frozen contract described in `docs/api-freeze-v1.md`.

## Contract

The FastAPI OpenAPI document is the machine-readable v1 contract. In development it is available at `/openapi.json`, `/docs`, and `/redoc`; release deployment assets set `API_DOCS_ENABLED=false` by default.

The current schema contains 124 operations across these groups:

| Area | Primary paths |
| --- | --- |
| Platform health | `/health`, `/ready`, `/metrics` |
| Asset and knowledge | `/assets`, `/knowledge` |
| Assessment | `/assessment/*` |
| Detection and telemetry | `/detection/*`, `/telemetry/*` |
| Incident and case | `/incidents`, `/cases` |
| Response | `/response/*` |
| Notification and ticket | `/notifications`, `/tickets` |
| Playbook and workflow | `/playbooks`, `/workflow` |
| Worker and sandbox | `/workers`, `/sandbox` |
| Registry and runtime | `/registry/*`, `/runtime/*`, `/tasks` |
| Governance | `/dashboard`, `/approvals`, `/audit`, `/roles`, `/permissions`, `/users`, `/settings`, `/plugins` |

## Authentication and authorization

Except for health, readiness, metrics, and enabled documentation paths, requests require the trusted proxy secret header and an identity header. The gateway must delete client-supplied values and inject verified values. UI visibility is not an authorization boundary; Backend RBAC is authoritative.

## Errors and correlation

Validation errors use HTTP 422. Authentication and authorization use 401/403. Domain errors map to explicit 4xx/5xx responses. Every request receives a request/trace correlation identifier in structured logs; clients should preserve W3C `traceparent` where supported.

## Stability

Path, Method, request/response schema, status semantics, enum values, required fields, and authorization requirements are governed by `docs/api-freeze-v1.md`.
