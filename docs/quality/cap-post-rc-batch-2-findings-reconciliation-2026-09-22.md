# Batch 2 findings reconciliation — prepared, deliberately NOT applied to the candidate

Prepared 2026-09-22 at `BATCH2_CANDIDATE_SHA = 257ba18d8cb6c22d330701b69713544254e4f03a`.

Why this is a file rather than a commit: the Batch 2 freeze forbids adding docs commits on top
of the frozen candidate, and editing `docs/known-issues.md` or `CHANGELOG.md` in the working
tree would make `git status` dirty at exactly the SHA the certification rounds are answering
for. So the reconciliation is written out here, per entry, and is meant to be applied **after**
the recertification verdict — as its own commit, which is a docs-only change (`INHERITED` per
`scripts/release/classify_diff.py`, so it cannot invalidate anything this round certified).

Every claim below is traceable to the report section named in it
(`docs/quality/cap-post-rc-batch-2-implementation-2026-09-22.md`).

## Open (new findings this round produced; neither was authorised to fix)

**F-44 — the pinned builder is not reliably what produces the bytes.** Observed across CI's five
release-image artifacts at the candidate: v0.37.0 on three images against the `v0.37.1` pin, and
the docker CLI's embedded BuildKit rather than setup-buildx's container. `f5a0cdd` made this a
field (`comparison.buildx_version.matches`) instead of an eye-diff. Whether a mismatch should
block publication is a gate decision Batch 2 never authorised, so it is reported, not absorbed.
Evidence: report §F.

**F-45 — a cancelled acquisition run could lose its terminal `CANCELLED` write.** Surfaced by CI
at `f5a0cdd` (`sqlite3.OperationalError: database is locked` on the worker's own last write): the
`WorkerCancelledError` branch never rolled back, so its abandoned uncommitted work held the
SQLite write lock the finalisation waited on. Fixed in `257ba18`: roll back like the four sibling
branches, land the terminal write and the lease release in one dedicated session/transaction, and
retry that write on transient lock markers with a bounded budget. Three property tests plus two
controls, all three red before the fix. Evidence: report §G.
