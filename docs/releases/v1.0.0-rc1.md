# Cyber Agent Platform 1.0.0-rc1 Release Notes

Release candidate date: 2026-08-05

## Purpose

`1.0.0-rc1` freezes the CAP v1 public API and packages the completed platform for Architect validation. It contains release engineering, deployment, documentation, security hardening, and certification evidence only; Phase 23 adds no business capability, Plugin, database model, Migration, or Platform Plane.

## Included platform areas

Asset, Knowledge, Assessment, Detection, Incident/Case, Response, Notification/Ticket, Worker, Sandbox, Telemetry, Playbook, Plugin governance, Web Console, RBAC, Approval, Audit, Metrics, Trace, and structured logging.

## Release engineering

- Backend, Frontend, SDK, Helm Chart, and image metadata use `1.0.0-rc1`.
- CI defines lint, type check, unit test, 95% coverage, frontend build, Compose/Helm validation, Docker build, npm audit, and Trivy scanning.
- Helm includes rolling Deployments, probes, PDBs, resource controls, external Secret references, and a migration hook.
- Compose rejects omitted production credentials and waits for healthy dependencies.

## Certification status

The RC is suitable for controlled staging and Architect review. It is **not an unconditional production certification**. Phase 22 recorded 9/11 performance budgets passing; high-concurrency API P95/P99 budgets failed. PostgreSQL/Redis restart, external HTTP load, Kubernetes rollout/rollback, image scanning, and target-capacity tests remain Production Entry Gates.

## Upgrade and rollback

Follow `docs/deployment/upgrade.md` and `docs/deployment/rollback.md`. Never mutate an already published `rc1`; corrections require `1.0.0-rc2`.
