## What shipped in 1.0.5 (relative to 1.0.4)

- **Worker lease-heartbeat race fix** (`0708012`) — cooperative teardown: a
  stop event plus interruptible wait replaces the bare
  `heartbeat_task.cancel()` in `WorkerRuntime.execute`'s finally. The old
  cancel could land while a TTL renewal UPDATE was in flight; the abandoned
  statement held the SQLite write lock in a zombie transaction until CPython
  GC finalised it, observed as a 22-33s "database is locked" stall in the
  release UPDATE. Full product-race triage:
  `docs/quality/flake-triage-34012500372-pregate-d.md`. Release latency
  22.27s -> ~62ms.
- **CI governance** (`f82b8cb`) — coverage-matrix accountability gate in CI:
  stdlib-only assertion + backend job fail-fast; every ❌ cell must carry an
  accountability anchor.
- **Frontend route-level code splitting** (`3ad23e5`) — 15 pages via
  `React.lazy`, antd manualChunks pin removed; 1213 kB monolith eliminated,
  first-paint gzip 437 -> 243 kB (-44%).
- **Real outbound probes** (`aa3774e`) — notification webhook/ticket tests
  now exercise a real HTTP round trip against a local asyncio acceptance
  server, clearing two coverage-matrix ❌ cells.
- **libuuid CVE remediation** (`000dee1`) — `apk upgrade --no-cache libuuid`
  clears 7 HIGH CVEs from the util-linux base-layer drift in the frontend
  image.
- **Worker-path test isolation** (`b0a0d76`) — per-test file-backed SQLite
  (NullPool+WAL+timeout) for 28.2 worker-path/claim-loop suites.
- **Assertion-semantics audit** (`53b9400`, docs) — zero defect-as-assertion
  findings (`docs/quality/assertion-semantics-audit.md`).
